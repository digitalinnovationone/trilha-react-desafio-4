# Desafio React - Login

Tela de login desenvolvida com React e TypeScript. O formulário valida e-mail e
senha com React Hook Form e Yup e informa os estados de validação,
autenticação e saída.

## Como executar

```bash
npm ci
npm start
```

A aplicação será iniciada em [http://localhost:3000](http://localhost:3000).

## Acesso de demonstração

- E-mail: `admin@dio.com`
- Senha: `123456`

A autenticação é local e serve apenas para demonstrar o fluxo do desafio. Para
uso real, conecte o formulário a um serviço de autenticação; credenciais
armazenadas no frontend não são seguras.

## Outros comandos

- `npm test -- --watchAll=false`: executa os testes.
- `npm run build`: gera a versão de produção em `build`.
